# Store screenshot shot list

Use real rendered app screens from the release build. Collection examples must come from a live, publication-safe test property checked on capture day.

## iPhone

1. **Tonight, answered clearly** — Today with next verified collection.
2. **The week ahead** — Schedule with multiple real collections and source status.
3. **Never miss bin night** — reminder settings after permission is granted.
4. **What goes where** — Guide results for a useful everyday item.
5. **Local options** — recycling centre/point with declared accepted materials.
6. **More than a link** — guided missed-bin eligibility and report tracking.

## iPad

Capture the same real-data story only after the physical iPad portrait, landscape, rotation, Split View, large-text and VoiceOver acceptance pass is complete. Include the adaptive left navigation in at least one portrait and one landscape image, using the current App Store Connect dimensions at submission time.

## Android

Use the same story, captured on Android with native system chrome and no iPhone frame.

## Optional web/PWA marketing

- Install prompt and standalone Home Screen experience.
- Honest unavailable/cached state.
- Exact property selection.

## Rules

- Do not expose a private home address.
- Do not fabricate dates or use static sample schedules in the app.
- Do not show “all councils” or “nationwide live dates.”
- Do not show Plus pricing in the proof release.
- Keep permission prompts out of screenshots unless explaining the permission.
- Use Apple/Google-required dimensions at the time of submission; store specifications can change.
